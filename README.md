# ProXimate

**Elegant, Modular, and Fast CSS Animation Framework**

**ProXimate** is a lightweight, plug-and-play CSS animation library built for modern web developers. Inspired by simplicity and performance, it delivers smooth, customizable animations that breathe life into your websites and applications — all through a simple class-based system.

---

## ✨ Features

- **Lightweight** – Just a few KBs minified.
- **Ready to Use** – Plug in via CDN and start animating.
- **Modular Classes** – Animate only what you need.
- **Performance Optimized** – GPU-accelerated transitions.
- **Customizable** – Easily override defaults with your own styles.
- **Responsive** – Works seamlessly across all devices.
