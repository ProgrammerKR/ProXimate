# Security Policy

## Supported Versions

Currently, the following versions of ProXimate are being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a high priority for ProXimate. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to us via email at `security@proximate-toolkit.com` (placeholder) or via GitHub Security Advisories if enabled on this repository.

### What to include

When reporting a vulnerability, please provide the following details:
* A description of the vulnerability and its impact.
* Steps to reproduce the issue.
* Any relevant code snippets or context.

### What to expect

We will acknowledge receipt of your vulnerability report within 48 hours. We strive to triage and address all reports promptly. Once a fix is prepared, we will coordinate with you to publish a security advisory and credit your discovery (if desired).

Thank you for helping keep the ProXimate community safe!
